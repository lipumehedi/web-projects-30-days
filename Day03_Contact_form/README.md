
# Day 03 - Contact Form

A simple contact form created using HTML5.

## 📌 Project Overview

This project is a basic contact form that allows users to enter
their personal information and send a message.

The project was created as part of my **30 Days Web Development Projects** challenge.

## 🛠️ Technologies Used

- HTML5

## 📚 What I Learned

- HTML Forms
- Input fields
- Labels
- Email input
- Telephone input
- Radio buttons
- Checkboxes
- Select dropdown
- Textarea
- Submit button
- Reset button
- Required fields
- Basic form validation

## ✨ Features

- Full Name field
- Email field
- Phone Number field
- Age input
- Subject dropdown
- Country dropdown
- Date of Birth
- Password field
- Preferred contact method
- Topic selection
- Message textarea
- Agreement checkbox
- Submit button
- Reset button

## 🚀 How to Run

1. Download or clone the repository.
2. Open the `Day-03-contact-form` folder.
3. Open `index.html` in a web browser.
