# Day 18 — Edit Tasks and Due Dates

## Project Overview

A responsive task manager built with HTML, CSS, and JavaScript. Users can add tasks, edit task names, assign due dates, search tasks, filter by status, and save data in Local Storage.

## Features

- Add, edit, and delete tasks
- Assign a due date
- Highlight overdue pending tasks
- Mark tasks as completed
- Search tasks by name
- Filter all, pending, and completed tasks
- Persist tasks using Local Storage
- Display task statistics
- Responsive layout

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Local Storage and JSON
- Array methods
- Event Listeners
- Date inputs

## How to Run

1. Open the folder in VS Code.
2. Open `index.html` using Live Server.
3. Add a task and optionally choose a due date.
4. Use Edit to change the task or deadline.
5. Refresh the browser to verify saved tasks.

## What I Learned

- How to edit an existing object in an array
- How to find an item using `find()`
- How to manage form state
- How to use date inputs
- How to calculate overdue status
- How to combine search, filtering, and Local Storage

## Limitations

Tasks are stored locally in the current browser and website origin. They are not synced across devices.
