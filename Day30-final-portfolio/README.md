# Day 30 — Personal Portfolio Website

A responsive personal portfolio built with HTML, CSS, and vanilla JavaScript as the final project of my 30 Days of Web Projects challenge.

## Features

- Responsive design for desktop, tablet, and mobile
- About Me and skills sections
- Featured project cards linked to GitHub
- Dark and light theme toggle
- Mobile navigation menu
- Automatically updated footer year
- Semantic HTML and keyboard focus styles

## Technologies

- HTML5
- CSS3
- JavaScript
- Git and GitHub

## Project Structure

```text
Day-30-final-portfolio/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Clone or download the repository.
2. Open `Day-30-final-portfolio/index.html` in a browser.
3. Alternatively, open the folder in VS Code and use the Live Server extension.

## Customization

- Update the introduction and skills in `index.html`.
- Add or remove projects in the `projects` array in `script.js`.
- Verify each GitHub project folder name and link.
- Update the statistics to reflect completed projects.
- Replace the placeholder avatar with a profile photo if desired.
