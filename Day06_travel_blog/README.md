
# Day 06 - Travel Blog Website

A simple travel blog website created using HTML5.

This project is part of my **30 Days Web Development Projects** challenge.

## 🛠️ Technologies Used

- HTML5

## 📚 What I Learned

- Semantic HTML
- Navigation links
- Articles and sections
- Images and hyperlinks
- Ordered and unordered lists
- Strong text formatting
- Internal page navigation

## ✨ Features

- Travel blog introduction
- Japan travel destinations
- Destination descriptions
- Travel tips
- Travel checklist
- Contact information
- Navigation menu

## 📂 Project Structure

```text
Day-06-travel-blog/
├── index.html
└── README.md
```

## 🚀 How to Run

1. Open the project folder in VS Code.
2. Open `index.html` in a browser.
3. Or use Live Server.

## 🎯 Goal

Practice HTML structure and create a simple travel blog.
