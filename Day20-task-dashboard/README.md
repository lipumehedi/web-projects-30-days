# Day 20 — Task Categories & Dashboard

A beginner-friendly task management dashboard built with HTML, CSS, and JavaScript.

## Features

- Add, edit, and delete tasks
- Organize tasks into Work, Study, Personal, and Other categories
- Set High, Medium, or Low priority
- Add due dates and identify overdue tasks
- Mark tasks as completed or pending
- Search tasks by name
- Filter tasks by category and status
- Sort by priority, due date, creation time, or task name
- View total, pending, and completed task counts
- Track completion rate with a progress bar
- View task counts for each category
- Store tasks in browser Local Storage
- Responsive layout for desktop and mobile

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Array Methods
- Local Storage

## How to Run

1. Clone or download the repository.
2. Open the `Day-20-task-dashboard` folder in VS Code.
3. Open `index.html` with a browser or use the Live Server extension.
4. Add tasks, choose categories, and explore the dashboard.

## What I Learned

- Organizing data using JavaScript objects and arrays
- Creating dashboard statistics dynamically
- Calculating completion percentages
- Filtering and sorting task data
- Updating the DOM with JavaScript
- Handling forms and user interactions
- Saving and loading data using Local Storage
- Building responsive web interfaces

## Limitations

Tasks are stored in the current browser only. They are not synchronized across devices or connected to a backend database.
