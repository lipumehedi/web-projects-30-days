# 🧠 Day 25 — Interactive Quiz App

An interactive multiple-choice quiz application built with HTML, CSS, and JavaScript. Answer JavaScript questions, receive instant feedback, and view your final score.

## ✨ Features

- 10 multiple-choice questions
- Four options per question
- Instant correct and incorrect answer feedback
- Correct answer highlighting
- Score tracking
- Question counter and progress bar
- Final score and performance message
- Restart quiz functionality
- Responsive design for mobile and desktop
- No external API required

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- DOM Manipulation
- Arrays and Objects
- Event Listeners
- Conditional Statements
- Functions

## 🚀 How to Run

1. Open the project folder in VS Code.
2. Open `index.html` with the Live Server extension.
3. Select an answer for each question.
4. Click **Next Question** to continue.
5. View your final score.
6. Click **Play Again** to restart the quiz.
