# Day 14 - Login & Signup Page

## Project Overview

A modern responsive login page created using HTML5 and CSS3.

The project demonstrates how to create a clean user authentication interface.

## Features

- Email input
- Password input
- Remember me checkbox
- Forgot password link
- Login button
- Create account link
- Responsive mobile design
- Input focus effects
- Button hover effects

## Technologies Used

- HTML5
- CSS3
- Flexbox
- Forms
- Media Queries
- CSS Transitions

## What I Learned

- How to create HTML forms
- How to use labels and input fields
- How to use email and password input types
- How to create responsive layouts
- How to use Flexbox
- How to create hover and focus effects
- How to make a website mobile-friendly
