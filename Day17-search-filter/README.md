# Day 17 — Search and Filter To-Do List

## Project Overview

A responsive To-Do List application built with HTML, CSS, and JavaScript. Users can search tasks, filter by completion status, and save their tasks in Local Storage.

## Features

- Add and delete tasks
- Mark tasks as completed
- Search tasks by text
- Filter all, pending, and completed tasks
- Display total, pending, and completed counts
- Persist tasks with Local Storage
- Clear all tasks with confirmation
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Local Storage
- JSON
- Array `filter()` method
- Event Listeners

## How to Run

1. Open the project in VS Code.
2. Open `index.html` using Live Server.
3. Add a few tasks.
4. Search by task name and try the status filters.
5. Refresh the browser to check Local Storage.
