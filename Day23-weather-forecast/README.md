# 🌦️ Day 23 — 7-Day Weather Forecast App

A responsive weather forecast application built with HTML, CSS, and JavaScript. Search for a city to view current weather and a seven-day forecast.

## ✨ Features

- Search for cities worldwide
- Display current temperature and weather conditions
- Seven-day weather forecast
- Daily minimum and maximum temperatures
- Weather condition descriptions and icons
- Maximum daily wind speed
- Loading and error messages
- Responsive layout for desktop and mobile
- No API key required

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- Async/Await
- Open-Meteo Geocoding API
- Open-Meteo Forecast API

## 📁 Project Structure

```text
Day-23-weather-forecast/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 How to Run

1. Open this folder in VS Code.
2. Start the application using the Live Server extension.
3. Enter a city such as Yokohama, Tokyo, or Dhaka.
4. Click Search.
5. Explore the current conditions and seven-day forecast.

An internet connection is required.
