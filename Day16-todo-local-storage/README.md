# Day 16 — To-Do List with Local Storage

## Project Overview

A responsive To-Do List application built with HTML, CSS, and JavaScript. Tasks are stored in browser Local Storage and restored after refreshing the page.

## Features

- Add tasks
- Mark tasks as completed
- Delete individual tasks
- Clear all tasks with confirmation
- Save and restore tasks with Local Storage
- Display total and completed task counts
- Responsive design
- Validate empty input

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Local Storage
- JSON
- Array Methods
- Event Listeners

## Project Structure

```text
Day-16-todo-local-storage/
├── index.html

└── README.md
```

## How to Run

1. Open the folder in VS Code.
2. Open `index.html` with Live Server.
3. Add, complete, and delete tasks.
4. Refresh the browser to confirm that tasks remain saved.
