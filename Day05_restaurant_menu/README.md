# Day 05 - Restaurant Menu Website

A simple restaurant menu website created using HTML5.

This project is part of my **30 Days Web Development Projects** challenge.

## 🛠️ Technologies Used

- HTML5

## 📚 What I Learned

- HTML tables
- Table rows and columns
- Table headings
- Ordered lists
- Unordered lists
- Semantic sections
- Navigation links
- Telephone links
- Email links

## ✨ Features

- Restaurant introduction
- Main food menu
- Food categories
- Food prices
- Popular items
- Drinks menu
- Opening hours
- Contact information
- Navigation menu

## 🚀 How to Run

Open `index.html` in a web browser.

You can also use Live Server in VS Code.

The goal of this project is to practice HTML tables,
