# Day 21 — Personal Expense Tracker

A beginner-friendly personal finance tracker built with HTML, CSS, and JavaScript.

## Features

- Add income and expense transactions
- Choose transaction categories
- Record transaction dates
- View total income, total expenses, and current balance
- Edit existing transactions
- Delete individual transactions
- Clear all transactions with confirmation
- Search transactions by description
- Filter by income, expense, and category
- Sort by date or amount
- Save transactions in browser Local Storage
- Responsive design for desktop and mobile

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Array Methods (`filter`, `reduce`, `sort`)
- Local Storage
- JavaScript Internationalization API

## How to Run

1. Clone or download the repository.
2. Open the `Day-21-expense-tracker` folder in VS Code.
3. Open `index.html` in a browser or use the Live Server extension.
4. Add income and expenses to explore the dashboard.

## What I Learned

- Managing financial data with JavaScript objects and arrays
- Calculating totals with `reduce()`
- Filtering and sorting transactions
- Handling form submissions and validation
- Updating the DOM dynamically
- Formatting amounts as Japanese yen
- Persisting data with Local Storage
- Building responsive interfaces

## Limitations

- Data is stored in the current browser only.
- Transactions are not synchronized between devices.
- This project does not connect to a bank or payment service.
- It is a learning project, not a financial application with server-side backup.
