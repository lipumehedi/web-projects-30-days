
# Day 12 - Admin Dashboard

A responsive admin dashboard built using HTML and CSS.

## Features
- Sidebar navigation
- Statistics cards
- Recent activities table
- Settings section
- Responsive layout
- Hover effects

## Technologies
- HTML5
- CSS3

## CSS Concepts Learned
- CSS Grid
- Grid Template Columns
- Fraction Units
- Minmax()
- Gap
- Media Queries
- Responsive Design
- Table Styling

## How to Run
Open `index.html` in a browser or use Live Server.
