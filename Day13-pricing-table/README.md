
# Day 13 - Pricing Table Website

## Project Overview
A responsive pricing table website built with HTML5 and CSS3.
It displays three subscription plans: Basic, Pro, and Premium.

## Features
- Three pricing plans
- Responsive layout using CSS Grid
- Hover animations on pricing cards
- Featured Pro plan
- Mobile-friendly design

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- Media Queries
- CSS Transitions

## What I Learned
- How to create responsive pricing cards
- How to use CSS Grid for layout
- How to style buttons and cards
- How to add hover animations
- How to use media queries for mobile screens
