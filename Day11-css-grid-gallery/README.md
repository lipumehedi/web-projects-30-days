
# Day 11 - CSS Grid Photo Gallery

A responsive Japan travel photo gallery built using HTML and CSS.

## Features
- Six travel destination cards
- Responsive photo gallery
- Hover animation
- About section
- Contact section
- Responsive desktop, tablet, and mobile layouts

## Technologies
- HTML5
- CSS3

## CSS Concepts Learned
- CSS Grid
- Grid Template Columns
- Repeat and Fraction Units
- Gap
- Object Fit
- Hover Effects
- Transitions
- Media Queries
- Responsive Design

## How to Run
Open `index.html` in a browser or use Live Server.
