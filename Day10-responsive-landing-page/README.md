# Day 10 - Responsive Travel Landing Page

A responsive travel landing page built using HTML and CSS.

## Features

- Responsive navigation
- Hero section
- Travel image
- Destination cards
- About section
- Contact section
- Responsive mobile layout
- Hover effects

## Technologies

- HTML5
- CSS3

## CSS Concepts Learned

- Flexbox
- Display Flex
- Justify Content
- Align Items
- Gap
- Flex Wrap
- Flex Direction
- Media Queries
- Responsive Design
- Box Sizing

## How to Run

Open `index.html` in a web browser or use Live Server.
