# 🍅 Day 26 — Pomodoro Timer

A simple and responsive Pomodoro Timer built with HTML, CSS, and JavaScript.

## ✨ Features

- 25-minute focus session
- 5-minute break session
- Start, Pause, and Reset controls
- Automatic switching between focus and break sessions
- Completed focus session counter
- Countdown display in MM:SS format
- Responsive design for mobile and desktop
- No external libraries required

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- `setInterval()` and `clearInterval()`

## 📂 Project Structure

```text
Day-26-pomodoro-timer/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Click **Start** to begin the timer.
