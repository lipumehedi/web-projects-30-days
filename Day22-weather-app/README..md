# ☀️ Day 22 — Weather App

A responsive weather application built with HTML, CSS, and JavaScript. Search for a city to see its current weather conditions using the Open-Meteo API.

## ✨ Features

- Search weather by city name
- Display current temperature in Celsius
- Show feels-like temperature
- Display relative humidity and wind speed
- Weather descriptions and emoji icons
- Loading indicator while searching
- Error handling for unknown cities and network failures
- Responsive design for mobile and desktop
- No API key required

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- Async/Await
- Open-Meteo Geocoding API
- Open-Meteo Weather Forecast API

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using the VS Code Live Server extension.
4. Enter a city name, such as `Yokohama`, `Tokyo`, or `Dhaka`.
5. Click **Search** to view the weather.

An internet connection is required to retrieve weather data.

Weather data: [Open-Meteo](https://open-meteo.com/)

City search: [Open-Meteo Geocoding API](https://open-meteo.com/en/docs/geocoding-api)
