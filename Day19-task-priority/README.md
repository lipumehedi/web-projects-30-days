# Day 19 — Task Priority Manager

A beginner-friendly JavaScript project that helps users organize tasks by priority and due date.

## Features

- Add new tasks
- Edit task names, due dates, and priorities
- Mark tasks as completed or pending
- Delete individual tasks
- Clear all tasks
- Set task priority: High, Medium, or Low
- Sort tasks by priority, due date, creation time, or task name
- Search tasks by name
- Filter all, pending, and completed tasks
- Highlight overdue tasks
- Save tasks in browser Local Storage
- Responsive layout for mobile and desktop

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Browser Local Storage

## How to Run

1. Clone or download this repository.
2. Open the `Day-19-task-priority` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Add tasks and experiment with the priority and sorting options.

## Limitations

Tasks are stored only in the current browser's Local Storage. They are not synchronized across devices or browsers.
